01 / 项目命题

让每一次操作，
都有明确的落点。

玩家从星图选择一处异常，阅读任务，确认出发，最后揭示并领取遗物。界面承担一件事：让这条链路始终清楚。

将三种视觉实验转为有具体职责的动效：聚焦建立选择，折叠连接层级，显影表达发现。信息、动作和反馈围绕同一个玩家目标组织。

03 / 界面与交互

四个界面，
一条连续的链路。

每一步都有主动作、阅读重点
和可以返回的位置。

玩家目标

我可以去哪里？

第七观测区呈现三处可回收的异常信号。中文节点名称与“已选中”标记帮助辨认当前目标。

动效职责 / 聚焦

局部环线和节点反馈建立焦点。任务摘要随选择更新，让空间位置与任务信息形成对应。

动作与退路

选择任务后查看详情；更换节点仍保留在同一张星图中。

玩家目标

这次任务值得出发吗？

阅读目标、风险与奖励，再进入出发确认。面板以任务为中心组织信息。

动效职责 / 折叠

从星图进入更具体的信息层级。展开与收回采用对应的方向，表达详情属于当前任务。

动作与退路

确认当前任务，或返回星图继续选择。

玩家目标

我准备好出发了吗？

主动作执行前再确认一次任务，将选择与行动分成清楚的两个阶段。

动效职责 / 承接

确认动作触发短暂过渡，提供“出发已经开始”的反馈。按钮先响应，演出再展开。

动作与退路

取消回到任务详情；确认后进入演示结算。本项目不包含战斗玩法。

玩家目标

我发现了什么？

截图记录遗物已识别、待领取的状态。揭示结束后显示名称与说明，供玩家阅读和领取。

动效职责 / 显影

扫描式显现构成发现的仪式感；演出结束后停稳，给信息与操作留出空间。

动作与退路

领取后显示已入库，阻止重复领取；返回星图开始下一次选择。

↔ 点击步骤切换界面；键盘可用左右方向键切换，用 Tab 移动到大图按钮后按 Enter 放大。

项目范围

这是已实现的原创概念游戏 UI 与动效原型，围绕任务选择、确认和奖励领取设计。任务、资源与结算均为演示内容；不包含战斗、服务器或真实存档。本案例没有开展用户研究，也不提供用户效果指标。

实现与素材

界面布局、按钮、信息组织和程序图形为本项目自制，以 HTML、CSS 与 JavaScript 实现。深空背景与遗物概念图使用 AI 辅助生成。字体许可与详细素材说明见项目 README。

体验方式

以 PC 端 1600 × 900 为设计基准，推荐桌面浏览器体验完整构图。可使用键盘选择与确认；系统开启“减少动态效果”时，过渡会简化。下载作品包后，可在本地打开首页与原型。
