# 《异物航线》视觉与动效参考

本轮重设计以原创远航员为视觉中心，采用骨白、墨蓝与珊瑚橙，组织「角色整备 → 任务星图 → 任务档案 → 出航确认 → 遗物揭示」五步。以下记录制作依据、实际核看的范围与本项目采用方式。原作者的方法说明和本项目的简化实现分别表述；界面与演出已制作，不将制作完成解释为用户效果已经验证。

## 1. Daanish Syed · Mortal Kombat 11

[原作者案例](https://www.daanishsyed.com/mk11) · [已核看的选人全景](https://images.squarespace-cdn.com/content/v1/55b97c34e4b07ffe1f5a908a/1594059512472-5H4E9PKASIISUBGO6P0Y/CharSelect_SCO_SUB.jpg)

**核看范围：**协作中已在原页查看静态构图：左右大人物、中间头像网格、金色选中焦点。作者另说明最终选人演出从近景拉远，装备定制结合镜头、角色动作、特效与声音；这部分依据作者文字，未声称完整观看视频。

**本项目采用：**角色整备以人物和姿态先建立身份，功能选择随后到达。切换步骤通过景别、裁切与图层位置变化承接人物，不把所有画面套进相同矩形卡片。遗物揭示安排独立的蓄光、显现与停稳段落；不复制格斗对峙、角色或原游戏界面。

## 2. Taylor Buck · Inventory + Gear Game UI

[原作者作品](https://taylor_buck.artstation.com/projects/Pmk8wB)

**核看范围：**协作中已查看首张静态图：右侧人物胸像、左侧装备网格，细线划分清晰模块；橙色标记当前标签，黄色边框表示具体选择。作者注明角色美术来自 Sam Leung，不能将人物画作归于 UI 作者。未核看该作品的完整动效。

**本项目采用：**角色整备用人物、细线、紧凑参数与少量装备标记形成构图。珊瑚橙集中表达当前选择与主动作；角色面部、任务标题和按钮各有明确阅读区域。保留必要信息密度，减少大面积空白卡片与重复宣传文案；不扩展完整装备系统。

## 3. takayuP4 · 游戏菜单与 UI 动效教程

[X 原帖](https://x.com/takayuP4/status/2087713700648218955) · [作者教程](https://gameanimation.info/en/archives/5601)

**核看范围：**协作中已从帖子进入教程并阅读正文，核对优先区域、角色中心、主动作及微弱环境动效原则。此处依据教程文字，不把未完整播放的嵌入视频描述为已观察结果。

**本项目采用：**每一步先确定人物或遗物的视觉重点，再安排任务信息与唯一主动作。环境动效保持微弱；选择、确认、揭示各在输入后集中发生。角色与信息使用错开的入场节拍，完成后停稳供阅读，不用持续漂移掩盖静态构图问题。

## 4. Náthaly Moyano · The Mother

[原作者案例与过程](https://nathalymoyano.com/work-themother)

**核看范围：**已阅读作者的界面、分层与动画过程说明。作者将需要动画的部位分离，用 UI 材质与时间轴处理呼吸、手部或面纱移动、饰物光泽，并强调清楚的按钮状态。本次未将完整影片作为已观看证据。

**本项目的简化实现：**两位远航员各使用完整的二维立绘，背景、程序光效与界面作为独立图层。人物采用整体位移、微小比例变化模拟呼吸与轻微视差，没有分离手部、外披或器具，也没有骨骼动画。遗物从三列图集中采样整件物品，以扫描线和矩形遮罩揭示；光核与外环没有拆成独立动画层。采用作者对层次、微动和清楚按钮状态的组织思路，揭示后保留名称与领取状态；未采用原作的肢体分层制作，也未沿用其题材、美术素材或符号。

## 使用边界

外部作品只用于构图、层次和时序研究，不直接复制或打包外部人物、截图、图标与视频。人物、任务与遗物保持本项目的原创身份；参考来源和作者说明与本项目实际实现分别记录。
